# 花生叶片病害数据集

## 数据集结构

```
peanut_disease/
├── images/
│   ├── train/          # 训练图像 (建议70-80%)
│   ├── val/            # 验证图像 (建议10-15%)
│   └── test/           # 测试图像 (建议10-15%)
└── labels/
    ├── train/          # 训练标签
    ├── val/            # 验证标签
    └── test/           # 测试标签
```

## 类别定义

- **0: Healthy** - 健康叶片
- **1: Early_Blight** - 早疫病
- **2: Late_Blight** - 晚疫病  
- **3: Leaf_Spot** - 叶斑病
- **4: Rust** - 锈病

## 标签格式 (YOLO格式)

每个图像对应一个同名的`.txt`标签文件，格式为：
```
class_id x_center y_center width height
```

**示例**:
```
0 0.5 0.3 0.2 0.15
1 0.7 0.6 0.15 0.12
```

**坐标说明**:
- 所有坐标都是归一化的 (0-1)
- x_center, y_center: 边界框中心点
- width, height: 边界框宽高

## 数据准备步骤

1. **收集图像**: 收集不同病害类型的花生叶片图像
2. **图像预处理**: 确保图像质量和尺寸合适
3. **数据标注**: 使用标注工具标记病害区域
4. **格式转换**: 将标注转换为YOLO格式
5. **数据分割**: 按比例分为train/val/test三个集合

## 推荐的数据集来源

1. **PlantVillage数据集**: 包含多种植物病害图像
2. **Kaggle农业数据集**: 搜索"plant disease"相关数据集
3. **自建数据集**: 使用LabelImg或CVAT进行标注

## 数据质量要求

- **图像分辨率**: 建议至少640x640像素
- **图像格式**: 支持JPG, JPEG, PNG, BMP
- **标注精度**: 边界框应准确框选病害区域
- **类别平衡**: 各类别样本数量尽量均衡

## 使用方法

将准备好的数据放入对应目录后，可以直接使用：

```bash
python train.py --data-path ./data/peanut_disease
```
